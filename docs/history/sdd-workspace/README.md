# Procedencia anterior a la distribución independiente

Estos registros proceden de
[SDD Workspace, commit 37b0f78](https://github.com/fdelvalle01/sdd-workspace/tree/37b0f7876bcb25f9308cbb3cd82b54c0ea052474/View-OpenSpec).
Describen los paquetes construidos cuando el Viewer estaba en `View-OpenSpec/`
y el motor en `Plantilla/scripts/conocimiento/` de ese repositorio.

Los JSON de [releases](releases/) conservan íntegros sus commits, hashes,
resultados y límites originales. [La validación histórica](validacion.md)
conserva su contenido y ajusta únicamente enlaces relativos para esta ubicación.
Las rutas de evidencias locales citadas pertenecían al entorno de origen.

No son builds ni resultados de CI del nuevo repositorio. Los instaladores
históricos permanecen en el Git original. La versión 0.3.2 de esta distribución
conserva comportamiento e identidad, pero tiene su propio paquete y
[procedencia](../../../releases/0.3.2.json). Su hash puede ser distinto al
histórico por las rutas de fuente, documentación y metadatos de empaquetado.
