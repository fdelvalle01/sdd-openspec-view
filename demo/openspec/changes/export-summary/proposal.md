# Exportar un resumen del catálogo

> **Simulación:** propuesta ficticia en fase inicial. No tiene diseño, tareas ni aprobación.

## Por qué

Una persona que consulta el catálogo de ejemplo quiere conservar una lista breve de los recursos visibles.

## Qué cambia

Se propone descargar un archivo de texto con el nombre y la descripción corta de cada recurso de la lista actual.

## Capacidades

- Nueva: `catalog-export`, todavía por especificar.

## Impacto

El alcance inicial afectaría a `catalog-web`. El formato final, el tratamiento de listas vacías y las tareas se definirían después de revisar la propuesta.
